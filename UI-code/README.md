# Chinify — کدهای UI

این پوشه از داخل `Chinify.apk` استخراج شده. این اپ یک اپ **هیبرید (Cordova + PWA)** است؛ یعنی تمام رابط کاربری با کد وب ساخته شده و داخل WebView اجرا می‌شود. سکلت اپ به این صورت است:

```
UI-code/
├── index.html            ← ورود اپ؛ سکلت صفحه (screen-host + tabbar + لایه‌ها)
├── native-bridge.js      ← پل ارتباطی اندروید (از assets/ اصلی APK)
├── manifest.webmanifest  ← تنظیمات PWA
├── service-worker.js     ← کش آفلاین
├── css/
│   ├── app.css           ← تمام استایل‌ها (~711KB، شامل تم، انیمیشن، کامپوننت‌ها)
│   ├── fonts/            ← فونت‌ها (Manrope، NotoSansSC، Kantumruy برای خمری)
│   └── icons/            ← آیکون‌های SVG رابط (لوکیشن، جستجو، تب‌بار و…)
├── js/                   ← ~78 ماژول جاوااسکریپت (کامنت‌دار و خوانا)
│   ├── ui.js             ← هسته رابط: رندر صفحه‌ها، تب‌بار، توست، لایه‌ها
│   ├── screens-*.js      ← صفحه‌های اپ (onboard / learn / pinyin / vocab /
│   │                        progress / strokes / pay / tools / me / extra)
│   ├── app.js            ← نقطه شروع و مدیریتی مسیریابی/استارت
│   ├── i18n*.js          ← ترجمه‌ها (پرتغالی، فرانسوی، اسپانیایی، ویتنامی،
│   │                        ارمنی، روسی، خمری)
│   ├── games.js / wheel.js / stack.js / town.js   ← بازی‌ها
│   ├── mascot-art.js / celebrate.js               ← گرافیک مسکات و افکت‌ها
│   ├── gestures.js / audio.js / speak.js / record.js ← صدا و لمس
│   ├── billing.js / store.js / screens-pay.js     ← پرداخت
│   └── vendor/hanzi-writer.min.js  ← کتابخانه انیمیشن قلم چینی (ثالث)
├── art/                  ← تصاویر UI (مسکات، پس‌زمینه، لوگوها، فرمت webp/svg)
├── icons/                ← آیکون‌های اپ (بوت‌اسکرین و…)
└── content/              ← محتوای آموزشی: درس‌ها، دیکشنری، pinyin، strokes،
                            دستور زبان، ویدیو، زیرنویس، و پادکست
```

- کدها **مینیفای نیستند** — کامنت فارسی/چینی/انگلیسیِ خودِ توسعه‌دهنده داخلشان هست و مستقیماً قابل مطالعه‌اند.
- XML های `res/layout` اندروید فقط قالب پیش‌فرض Cordova/Capacitor بودند و نقشی در UI ندارند؛ به همین دلیل کپی نشدند.
- `js/build.js` و `js/config.js` ورژن و تنظیمات بیلد را نگه می‌دارند.

برای دیدن اپ به شکل واقعی: یک وب‌سرور ساده روی همین پوشه بزنید
(`python -m http.server` از داخل `UI-code`) و `index.html` را در مرورگر باز کنید.
(بخش‌های وابسته به پلاگین‌های اندروید مثل پرداخت و نوتیفیکیشن فقط داخل خود اپ کار می‌کنند.)
